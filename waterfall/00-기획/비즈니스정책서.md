## 1. 문서 개요

### 1.1 목적

블로그 목록·이메일·설정·리포트 분석이 동일한 사용자 상태와 조건을 사용하도록 한다. 사이트 소유자는 범위와 예외를 검토하고, 구현 담당자와 Codex는 구체 규칙 ID를 기능·테스트에 연결한다. 별도 운영·QA 조직이 있다고 가정하지 않는다.

### 1.2 정책 작성 가이드

- 각 정책 분류는 목적·규칙·정상/경계/오류 예시·변경이력을 갖는다. 규칙의 근거는 PRD 장·MVP·AC에 연결한다.
- BP-AUTH는 분류이고 BP-AUTH-001은 실행 가능한 개별 규칙이다. 후속 SRS·유스케이스·RTM은 분류가 아니라 개별 ID를 참조한다.
- PRD에 없는 세부 동작은 아래 미결 참조에 명시한다. 미결은 구현자가 임의로 선택해도 된다는 뜻이 아니다.
- 기능 범위는 [PRD](../../PRD.md), 사용자 가치와 미결 결정의 원장은 [서비스 기획서 7.3](서비스기획서.md#73-가정의존성미결-결정), 시각적 근거는 [DESIGN.md](../../DESIGN.md)를 사용한다.
- 개인정보 처리·세션·삭제 기간 등 확인되지 않은 수치는 범용 예시에서 가져오지 않는다.

## 3. 인증/권한 정책

### 3.1 목적

소유자의 개인 구독·읽기 기록·설정을 보호하고 외부 AI 계정 접근과 사이트 인증을 분리한다.

### 3.2 규칙

| 규칙 ID | 규칙 | 근거·연결 |
|---------|------|-----------|
| BP-AUTH-001 | 개인 화면·데이터·설정은 인증된 소유자만 접근한다. 공개 회원가입과 다른 사용자 역할은 제공하지 않는다. 소유자 확인 수단·세션 조건은 DEC-001 확정 후 상세화한다 | PRD 2.1·8 / MVP-001 / AC-001 |
| BP-AUTH-002 | 이메일 자격증명·DB 접속 정보는 서버에만 두고 저장소·클라이언트·일반 로그에 노출하지 않는다. ChatGPT·Claude 비밀번호·쿠키·API 키 입력란을 제공하지 않는다 | PRD 5.2·8 / MVP-001·008 |

### 3.3 예시

| 유형 | 관련 규칙 | 상황 | 결과 |
|------|-----------|------|------|
| 정상 | BP-AUTH-001 | 인증된 소유자가 구독 설정을 연다 | 개인 설정 조회·변경 허용 |
| 경계 | BP-AUTH-001 | 외부 원문 링크를 여는 경우 | 원문 사이트로 직접 이동. 원문 접근에 사이트 로그인 강제 없음 |
| 오류 | BP-AUTH-001·002 | 비소유자가 개인 데이터에 접근하거나 외부 AI 비밀번호 입력을 요구하는 흐름 | 개인 데이터 거절. 외부 계정 입력은 AI 서비스의 공식 화면에서만 수행 |

### 3.4 변경이력

2026-11-24 v0.1: BP-AUTH-001·002 초안 작성. 승인 기록 없음. 이후 변경은 13.3에 기록한다.

## 4. 운영비용 정책

### 4.1 목적

개인용 서비스에 불필요한 결제 기능을 만들지 않고 사이트 운영비와 외부 AI 이용 조건을 구분한다.

### 4.2 규칙

| 규칙 ID | 규칙 | 근거·연결 |
|---------|------|-----------|
| BP-COST-001 | 첫 버전에는 사이트 결제·회원 등급·무료 체험·환불·광고·AI API 호출을 넣지 않는다. 운영비·이메일 예산은 DEC-001·002, 외부 AI 이용 조건은 소유자가 해당 서비스에서 확인한다 | PRD EX-001·006, 8장 / MVP-001·008 |

### 4.3 예시

| 유형 | 관련 규칙 | 상황 | 결과 |
|------|-----------|------|------|
| 정상 | BP-COST-001 | 리포트 분석을 켠다 | 결제·API 키 요구 없이 요청문 준비 사용 |
| 경계 | BP-COST-001 | 외부 AI 서비스에서 사용 한도가 표시된다 | 사이트가 이용 한도·권한을 대신 부여하거나 무료 이용을 보장하지 않음 |
| 오류 | BP-COST-001 | 이메일 제공업체 제한으로 발송 실패 | BP-ERROR-003에 따라 실패 처리. 소유자에게 유료 회원 전환을 요구하지 않음 |

### 4.4 변경이력

2026-11-24 v0.1: BP-COST-001 초안 작성. 승인 기록 없음.

## 5. 콘텐츠 접근·수집 정책

### 5.1 목적

관심 기술 글을 빠짐없이 모으면서 초기 과거 글·중복·수정 글이 새 글 알림으로 섞이지 않게 한다.

### 5.2 규칙

| 규칙 ID | 규칙 | 근거·연결 |
|---------|------|-----------|
| BP-CONTENT-001 | 기본 제공 목록은 NAVER D2·카카오테크·우아한형제들·삼성SDS·SK플래닛 TECH TOPIC이며 수집 대상을 이 목록으로 제한하지 않는다. 구독한 공개 피드·목록이 제공하는 모든 새 글을 수집한다. 기술 글·채용·행사 모집·일반 기업 소식·기술 설명 없는 홍보를 모두 포함하고 유형으로 수집·목록·브리핑에서 자동 제외하지 않는다. 초기 과거 글·중복·구독·날짜·삭제 조건은 유지한다 | PRD 4.1 / MVP-002·003·004·005 / AC-020 |
| BP-CONTENT-002 | RSS·Atom을 우선하고 없으면 공개 목록을 수집한다. 1시간마다 실행하며 07:30 최종 수집을 추가한다. 출처별 게시물 ID 또는 원문 주소로 동일 글을 판정하고 기존 글 수정은 재알림하지 않는다 | PRD 4.1·4.2 / MVP-003 / AC-002 |
| BP-CONTENT-003 | 기본·사용자 출처 모두 처음 연동할 때 발견한 글은 과거 글로 등록하고 신규 알림에서 제외한다. 삭제 후 재추가 시 초기 기준을 다시 잡고, 기존 글을 재사용해 중복 생성·삭제 기간 글 소급 알림을 방지한다 | PRD 4.1.1·4.2 / MVP-002·003 / AC-003·017·019 |
| BP-CONTENT-004 | 구독을 켠 뒤 새로 발견한 해당 출처 글을 알림 후보로 삼는다. 해제한 출처의 글은 새 알림에서 제외하며 재구독 시 해제 기간 글을 소급 발송하지 않는다. 재구독 이전부터 대기하던 글·발송 경계의 구독 변경 처리는 DEC-006에서 확정한다 | PRD 4.2 / MVP-002·003 / AC-003 |
| BP-CONTENT-005 | 제목·기업·게시일·원문 링크와 제공된 소개·태그를 표시하고 원문 전체를 재게시하지 않는다. 전체 글은 최신순·제목 검색·기업/읽음 필터를 제공한다. 오늘의 글은 해당 날짜 브리핑 기준이다. 콘텐츠 유형에 따른 자동 제외 없이 원하지 않는 글을 사용자가 목록에서 직접 숨길 수 있다 | PRD 4.1·4.3 / MVP-004 / AC-004 |
| BP-CONTENT-006 | 읽음·저장·저장 해제는 사용자의 명시적 조작으로 변경한다. 원문 열기·리포트 분석 이동만으로 읽음 처리하지 않는다. 읽음·저장 변경을 알림 수신 조건으로 추가하지 않는다 | PRD 4.3 / MVP-006 / AC-004 |
| BP-CONTENT-007 | 구독 설정에서 공개 기술 블로그·글 목록·RSS/Atom URL을 직접 추가할 수 있다. 연결 확인은 사용자 조작 이후 실행하고 발견한 출처명·실제 수집 URL을 보여준다. 피드가 여러 개면 사용자가 선택한다. 추가 후 초기 글 처리가 끝나기 전에는 수집 대기 상태를 표시한다 | PRD 4.1.1 / MVP-002·003 / AC-017 |
| BP-CONTENT-008 | 등록 전 연결·수집 가능 여부를 확인한다. RSS/Atom을 찾지 못하면 기존 지원 수집기가 있는 공개 목록만 허용한다. 잘못된 URL·연결 실패·미지원은 원인과 수정 방법을 안내하며 등록 완료로 표시하지 않는다. 공개 HTTP(S)만 조회하고 인증정보·localhost·사설/내부 주소를 거절하며 DNS·리다이렉트 목적지도 검증한다. 조회 시간·응답 크기 한도는 DEC-003에서 확정한다 | PRD 4.1.1·8 / MVP-002·003 / AC-018 |

## 부록

### A. 정책 ID 체계

BP-분류는 목차용이고 BP-분류-3자리번호는 구체 동작을 참조하는 ID다. 본 문서는 불필요한 다단계 ID를 추가하지 않는다. 규칙 표의 ID를 SRS·유스케이스·RTM에서 동일하게 사용한다.

### B. 용어 정의

| 용어 | 정의 |
|------|------|
| 구독 | 블로그 출처의 새 글 수신 선택. 유료 계약과 무관 |
| 알림 일시 중지 | 수집·읽기는 유지하고 이메일 발송만 중지 |
| 최초 발견일 | 해당 글을 수집기가 처음 등록한 한국 날짜 |
| 초기 과거 글 | 출처 최초 연동에서 발견해 새 글 알림에서 제외한 글 |
| 브리핑 | 날짜별 대상 글 묶음. 이메일 표시 건수와 전체 건수는 다를 수 있음 |
| 수동 AI 인계 | 요청문 복사와 외부 공식 서비스 열기 후 사용자가 실행하는 흐름 |
| 발송 성공 불명확 | 요청 결과만으로 실제 전송 여부를 판단할 수 없는 상태 |
| DEC | 서비스 기획서 7.3에서 담당·결정 시점·영향을 관리하는 미결 결정 ID |
