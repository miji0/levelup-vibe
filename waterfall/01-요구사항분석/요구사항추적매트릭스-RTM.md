## 1. 목적

기획 문제·MVP·구체 정책 → SRS FR/NFR·자체 수용 기준 → UC → 후속 설계·코드·TC·실행 증빙을 추적한다. 출처와 검증 조건은 지금 연결하고 실제 존재하지 않는 설계 절·커밋·테스트 결과는 만들지 않는다.

## 3. 상태 정의

### 3.1 요구사항 상태

| 상태 | 기준 |
| --- | --- |
| 초안 | 현재 모든 요구사항. 출처·SC 작성, 소유자 검토 전 |
| 승인 | 실제 G1 대상 버전·승인 근거 기록 후 사용 |
| 변경중·보류·삭제 | 소유자의 변경 결정·사유·영향·적용 버전 연결 시 사용 |

### 3.2 매핑 상태

| 구분 | 현재 상태 |
| --- | --- |
| 출처·SC | 연결됨. 동작 검증 결과와 다름 |
| UC | 모든 FR에 흐름 연결. NFR는 관련 흐름 또는 구조 검증으로 연결 |
| 시스템 설계 | 실제 SAD/DB/API/UI 초안의 절·표에 연결. 승인·구현 증빙과 다름 |
| 상세 설계 | DDS의 처리 절차·상태·코딩 표준에 33개 요구사항 연결. 구현/실행 증빙과 다름 |
| 구현 | 미착수. 04에 예정 경로·기술 변경·인계 조건 작성, 실제 코드/커밋 없음 |
| TC | 미작성. 05-테스트의 범용 예시는 연결한 실제 TC가 아님 |
| 실행·판정·증빙 | 미실행 / 없음. 제품 통과·승인 없음 |

## 6. 커버리지 요약

분모는 현재 첫 릴리스의 포함 요구사항 33개(기능 23 + 비기능 10)다. 이는 문서 추적 현황이며 승인된 기준선·실행률이 아니다.

| 지표 | 계산 | 현재 실적 |
| --- | --- | --- |
| 출처·수용 기준 연결 | 기획/정책과 SC가 있는 요구사항 / 33 | 33 / 33 = 100% — 문서 연결만 의미 |
| 기능 UC 연결 | UC가 연결된 기능 요구사항 / 23 | 23 / 23 = 100% — 시나리오 작성만 의미 |
| 설계 매핑률 | 실제 시스템 설계 참조가 있는 요구사항 / 33 | 33 / 33 = 100% — 초안 연결, 승인/검증 아님 |
| 상세 설계 매핑률 | 실제 DDS 절이 연결된 요구사항 / 33 | 33 / 33 = 100% — 초안 연결, 승인/검증 아님 |
| 구현 매핑률 | 실제 코드/커밋 참조가 있는 요구사항 / 33 | 0 / 33 = 0% |
| 테스트 매핑률 | 작성된 실제 TC가 연결된 요구사항 / 33 | 0 / 33 = 0% |
| 수용 기준 검증 완료율 | 필수 기준을 실제 검증한 요구사항 / 33 | 0 / 33 = 0% |
| TC 실행률·통과율 | 실제 실행 TC 기준 | 산정 불가 — 작성·실행한 제품 TC 없음 |

상위 범위는 MVP 9개, PRD AC 20개, 구체 BP 37개 모두 역추적 표에 연결되어 있다. 합의되지 않은 미결을 해소하거나 테스트를 통과했다는 뜻은 아니다.
